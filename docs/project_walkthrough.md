# Portfolio walkthrough

## Scenario
A fictional healthcare technology company uses four external service providers. The GRC team must document inherent vendor risk, identify missing assurance evidence, track remediation and communicate operational metrics.

## What to demonstrate in an interview
- Explain why PHI access increases diligence requirements and why BAA status is tracked separately from inherent risk.
- Show how the 5x5 matrix prioritizes vendors, then explain why residual risk requires control effectiveness assessment.
- Point out the overdue critical MFA finding and explain an escalation path.
- Walk through a vendor's SOC 2 evidence gap and remediation ownership.
- Show how Python converts CSV registers into repeatable JSON and HTML reporting.
- Describe limits: no live GRC integration, no real vendor data, no automated compliance certification.

## Planned enhancements
- Configurable scoring and due-date SLA policy.
- Risk exception approvals and expiry.
- Evidence metadata and review reminders.
- ServiceNow/LogicGate integration using mock APIs first.
- Role-based access control for an internal dashboard.
