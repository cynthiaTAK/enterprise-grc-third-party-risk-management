# Illustrative control mapping

This is an educational crosswalk, **not** an official compliance determination. Confirm current framework versions and control applicability before production use.

| Control area | Example NIST SP 800-53 control | Evidence example | Program owner |
|---|---|---|---|
| Account lifecycle | AC-2 | Access review export and approval | IT / Security |
| Multi-factor authentication | IA-2 | MFA policy and enforcement screenshot | IAM |
| Security assessments | CA-2 | Assessment report | GRC |
| Contingency backup | CP-9 | Backup and restore test records | Infrastructure |
| Supplier assessments | SR-6 | Vendor risk assessment | Third-Party Risk |

HIPAA, SOC 2, ISO 27001 and PCI DSS applicability depends on organization, scope and data flows. A SOC 2 report is evidence to evaluate, not proof that all controls are effective.
